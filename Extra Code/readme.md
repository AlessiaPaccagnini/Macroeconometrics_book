 **DSGE Models with Stochastic Volatility and Student-t Shocks**

As an additional computational resource for readers interested in extending the DSGE methods discussed in the book, the **DSGE-SVt MATLAB Toolbox** provides tools for the Bayesian analysis of high-dimensional DSGE models with Student-t shocks and stochastic volatility.

The MATLAB® programs in this package perform Bayesian analysis of high-dimensional DSGE models with Student-t shocks and stochastic volatility. The toolbox simulates the posterior distribution using the tailored randomized-block Metropolis–Hastings (TaRB-MH) algorithm of Chib and Ramamurthy (2010), calculates the marginal likelihood using the methods of Chib (1995) and Chib and Jeliazkov (2001), and includes a range of post-estimation tools.

For further details, see the accompanying paper by Chib, Shin and Tan (2020), *“DSGE-SVt: An Econometric Toolkit for High-Dimensional DSGE Models with SV and t Errors.”*

**Code and documentation:** [DSGE-SVt MATLAB Toolbox on GitHub](https://github.com/econdojo/dsge-svt)
